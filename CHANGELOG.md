# Changelog

## 0.6.1 — Prepared, not publicly released

- Starter PDF body text is left-aligned to match Word, retaining paragraph
  indentation and spacing while keeping caption formatting separate.
- Build diagnostics tolerate malformed UTF-8 without bypassing failed-command,
  missing-glyph or reference checks.

- Numbered Canvas citations are compact, blue and borderless; citation editing
  and metadata tooltips remain available.
- Public-facing README, authoring/build/reference/collaboration guides and
  contributor instructions are separated from detailed development constraints.
- Runtime and development Python dependency lists are explicit.
- Generic starter paths, CLI examples and bibliography request identification
  replace lab-specific placeholders; existing license attribution is preserved.
- Local VSIX packaging preserves relative documentation links when no public
  repository URL is configured.

This is a release-preparation checkpoint, not a claim of GitHub or Marketplace
publication. Earlier private development remains in private Git history; no
public release chronology is inferred from that history.
