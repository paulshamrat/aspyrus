# Changelog

## 0.6.1 — Initial Public Release

- **Visual LaTeX Editing:** Distraction-free Canvas editing directly inside VS Code and compatible editors, keeping the `.tex` file 100% authoritative.
- **Typography Alignment:** Starter PDF body text is left-aligned to match Word, retaining paragraph indentation and spacing while keeping caption formatting separate.
- **Robust Build Diagnostics:** Diagnostics tolerate malformed UTF-8 and modern tagged PDF streams while enforcing strict reference, glyph, and prose parity checks.
- **Interactive Citations:** Numbered Canvas citations are compact, blue, and borderless, with inline citation editing, numbering, and metadata tooltips.
- **Self-Contained Packaging:** Bundled and distributed as an ultra-lightweight `.vsix` extension package.
